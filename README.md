# 🌦️ Israel Weather MCP Server

פרויקט זה מממש שרת **MCP (Model Context Protocol)** המאפשר למודלי שפה (LLMs) לקבל מידע חי ומדויק על מזג האוויר בישראל באמצעות אוטומציית דפדפן (Playwright). 

בניגוד לשרתים המבוססים על API סטטי, השרת הזה מסוגל לאחזר נתונים דינמיים על ידי ניווט באתר מזג אוויר, הזנת שאילתות וחילוץ מידע רלוונטי ישירות מה-DOM (טכניקת Real-time RAG).

## 🛠️ טכנולוגיות
*   **Python (FastMCP SDK)** - תשתית הפרוטוקול לחיבור השרת למודל.
*   **Playwright** - כלי מתקדם לאוטומציה ושליטה בדפדפן Chromium.
*   **Asynchronous Programming** - עבודה אסינכרונית לביצועים אופטימליים.

## 🚀 הוראות הרצה

### 1. הכנת הסביבה
הפרויקט מבוסס על מנהל החבילות `uv`. להפעלת הסביבה והתקנת התלויות:
```bash
# סנכרון חבילות והפעלת סביבת עבודה
uv sync

# התקנת דפדפן עבור Playwright
uv run playwright install chromium 
```

יש ליצור קובץ `.env` בתיקיית הפרויקט עם מפתח ה-API של Anthropic:
```
ANTHROPIC_API_KEY=your-api-key
```
### 2. הרצת ממשק המשתמש (Gradio)
ממשק צ'אט בדפדפן, שמציג רק את התשובה הסופית (קריאות הכלים מוצגות רק בהרצה בטרמינל):

```bash
uv run app.py
```
הממשק ייפתח אוטומטית בכתובת http://127.0.0.1:7860

### 3. הרצה בטרמינל (ללא ממשק)
```bash
uv run host.py
```
## 🧩 הכלים הזמינים (Tools)
השרת חושף ארבעה כלים מרכזיים המאפשרים למודל אינטראקציה מלאה עם האתר:

**open_weather_forecast_israel**: אתחול הדפדפן וטעינת אתר היעד.

**enter_weather_forecast_city_israel**: הזנה דינמית של שם העיר המבוקשת.

**select_weather_forecast_city_israel**: בחירה מהרשימה וניווט לדף התחזית המפורט.

**get_weather_page_content**: חילוץ וניקוי טקסט מהדף והעברתו כקונטקסט למודל.

## 💡 דוגמאות לשימוש
הסוכן יודע לבצע שרשרת פעולות (Chaining) באופן עצמאי כדי לענות על שאלות כגון:

"מה מזג האוויר בתל אביב כרגע?"

"מה מצב הרוחות והטמפרטורה בירושלים?"

"תשיג לי את התחזית המעודכנת לעיר חיפה."

### ⚙️ הגדרות דפדפן ותאימות (Technical Configurations)
**Browser Management:** השרת מוגדר לעבוד במצב Headed (דפדפן גלוי) כברירת מחדל, המאפשר מעקב ויזואלי אחר פעולות הסוכן בזמן אמת.


**Direct DOM Manipulation:** שימוש בשיטת evaluate להזרקת נתונים ישירות לשכבת ה-DOM. טכניקה זו מבטיחה אינטראקציה יציבה עם שדות קלט גם כאשר קיימות שכבות ויזואליות חוסמות (כגון חלוניות אישור או באנרים).

**Automation Stealth:** הזרקת סקריפטים לנטרול זיהוי אוטומציה, המאפשרת חוויית גלישה חלקה וטעינה תקינה של משאבי האתר.
